# Overview

Wedding Face Finder is an AI-powered face recognition web application for wedding and event photographers. Guests upload a selfie and instantly find every photo they appear in across thousands of event images.

## Key Features

- CNN + HOG face detection cascade
- 128-dimension face encoding matching
- Sub-3-second search on 4,600+ photos
- Client-side image compression
- GDPR-compliant auto-purge
- AES-256 encryption at rest
- Full audit logging
