# Privacy & GDPR

## Data Minimization

- Only face encodings (128-d float arrays) are stored long-term
- Original photos can be purged immediately after processing
- No facial data used for model training

## User Rights

- **Access**: All photos and encodings associated with an event
- **Deletion**: One-click purge removes all data
- **Portability**: ZIP download of all matched photos

## Retention

Default: 30 days automatic deletion. Configurable per event.
